About The Standup Memory Game

I'm Robin, and I made this game to turn the decisions, updates and useful details from short standup meetings into a quick memory quiz. Read a question, choose an answer and see what you remembered.

How to play

Enter a name and start a quiz. Questions appear one at a time with a set of possible answers. The game highlights the correct choice after you answer and may show an explanation, so each question can be a reminder as well as a test. You earn one point for each correct answer. At the end, your score is shown alongside the number of questions answered.

Some questions include a source link. Open it if you want to revisit the background or check the context behind a topic. The source is part of the question: the aim is to remember information in context, not just guess a phrase.

A small retrieval-practice game

Trying to recall a detail before seeing the answer is a simple way to check what stuck. The game makes that check light and repeatable: answer, get immediate feedback, and continue. It is designed as an individual memory challenge, not as a measure of someone’s work performance.

Questions come from the set prepared for the game, so the experience reflects those topics rather than every possible standup meeting. A round is a snapshot of that question set; scores are most meaningful when compared among people answering the same set.

Scores and names

Completed quizzes can be recorded on the high-scores page. The board compares the number of correct answers and shows how many questions each player answered. Choose a nickname if you would rather not display your full name on the leaderboard.
